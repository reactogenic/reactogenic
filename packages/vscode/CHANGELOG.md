# Changelog

## 0.1.1 — pre-release

The first release.

- Syntax highlighting for `.rtsx`, and for ```` ```rtsx ```` fences in
  Markdown.
- The language server (`reactogenic lsp`): diagnostics in slot terms, hover,
  completion, definitions, references, rename, auto-import, quick fixes,
  closing tags.
- Slots and segments: definitions from a slot tag and from a segment root;
  rename from any tag of a slot.
- `.rtsx` modules in VS Code's own TypeScript (`.ts` and `.tsx` files).
- *Show Transpiled TSX*, *Restart Server*, the *reactogenic: check* task.
